# Mobile Expense & Income Tracking App (React Native Expo)

React Native Expo နှင့် `expo-sqlite` ကို အသုံးပြု၍ တည်ဆောက်ထားသော ကိုယ်ပိုင်ဝင်ငွေ/ထွက်ငွေ စာရင်းရှင်းတမ်း (Finance Tracker) မိုဘိုင်းအက်ပ် ဖြစ်သည်။ ဒေတာများကို ဖုန်းအတွင်း SQLite ဒေတာဘေ့စ်တွင် လုံခြုံစွာ သိမ်းဆည်းပေးပါသည်။

---

## ထူးခြားချက်များ (Features)

- **ဝင်ငွေနှင့် ထွက်ငွေ စီမံခန့်ခွဲခြင်း:** ဝင်ငွေ (Income) နှင့် ထွက်ငွေ (Expense) များကို သီးခြား Tab များခွဲ၍ မှတ်တမ်းတင်နိုင်ခြင်း။
- **အချိန်နှင့်တပြေးညီ တွက်ချက်မှု (Real-time Balance):** စုစုပေါင်း ဝင်ငွေ၊ ထွက်ငွေနှင့် လက်ကျန်ငွေ (Balance) များကို အလိုအလျောက် တွက်ချက်ပြသပေးခြင်း။
- **Local SQLite Database:** အင်တာနက် မလိုဘဲ ဖုန်းအတွင်း၌ပင် ဒေတာများကို လုံခြုံစိတ်ချစွာ သိမ်းဆည်းပေးခြင်း။
- **အချက်အလက် ပြင်ဆင်ခြင်းနှင့် ဖျက်ခြင်း (CRUD):** 
  - မှတ်တမ်းတစ်ခုချင်းစီ၏ အကြောင်းအရာ၊ ပမာဏနှင့် ရက်စွဲ (Date) တို့ကို လိုသလို ပြင်ဆင်နိုင်ခြင်း (ရက်စွဲကို နှိပ်၍ သို့မဟုတ် 'ပြင်ရန်' ခလုတ်ကို နှိပ်၍ ပြင်ဆင်နိုင်သည်)။
  - မှတ်တမ်းတစ်ခုချင်းစီ သို့မဟုတ် အားလုံးကို တစ်ခါတည်း ဖျက်ပစ်နိုင်ခြင်း။
- **မြန်မာဘာသာဖြင့် သတိပေးချက်များ:** အသုံးပြုရ လွယ်ကူစေရန် မြန်မာဘာသာဖြင့် Alert များနှင့် UI များကို စီစဉ်ထားခြင်း။

---

## 🛠 အသုံးပြုထားသော နည်းပညာများ (Tech Stack)

- **Database:** `expo-sqlite`
- **Styling:** React Native StyleSheet
